# Recorded environment

Source capture, raw OOXML projection and independent original-cell reads used CPython 3.12.14, Openpyxl 3.1.5 and lxml 6.1.1. The initial exact development/later analyses used CPython 3.10.11 with the standard library. Requirements pin the source/figure/PDF libraries; no learned model, random seed, GPU, paid service or source account is used.

Figures use Matplotlib 3.10.9. The manuscript was compiled with Tectonic and inspected as six Poppler-rendered pages at 95 dpi; PDF text/source arithmetic uses pypdf 6.10.0. Public numerical replay runs without source network retrieval. Original workbook hashes and native representation are retained in the source receipt. The original source files and source PDF are outside the public repository.
