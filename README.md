# Keep cotton quality in a price alert

A price pipeline can signal a jump when a report adds a different quality, even if the original quote has not changed. USDA announced an additional cotton quality in its August 2025 report format. This study will use historical official price grids to test that ingestion risk with explicit controlled cases.

**Current state: protocol before historical workbook capture.** No alert precision, operational benefit or actual price anomaly is established. The [protocol](PROTOCOL.md) separates official quotations from authored changes and missing-identity cases. Independent program manuscripts may be public after checks; Azure and other formal-publication projects remain private.
